# ProgWeb I e II - 4º Ano

## 📖 Sobre o Projeto

Este repositório contém os itens da unidade curricular (UC) de Programação Web desenvolvidos durante o primeiro e segundo ano do curso.

## 📋 Descrição

Repositório dedicado ao armazenamento e organização de materiais, projetos e recursos relacionados à disciplina de Programação Web, abrangendo conteúdos tanto do primeiro quanto do segundo ano acadêmico.

## 🎯 Objetivos

- Centralizar materiais didáticos de Programação Web
- Documentar o progresso e aprendizado ao longo dos anos
- Facilitar o acesso a projetos e exercícios desenvolvidos
- Servir como portfólio de trabalhos realizados

## 📁 Estrutura do Repositório

O repositório está organizado para incluir materiais de:
- **Primeiro Ano**: Fundamentos e conceitos iniciais de Programação Web
- **Segundo Ano**: Conceitos avançados e projetos mais complexos

## 🚀 Tecnologias

As tecnologias utilizadas ao longo do curso podem incluir:
- HTML/CSS
- JavaScript
- Frameworks e bibliotecas web
- Ferramentas de desenvolvimento web
